# Support

## Before you open an issue

Most connection problems are covered in the [FAQ](https://www.picaroa.app/en/faq/).
If something behaves oddly, check whether the same happens in the PicoShare web interface —
if it does, the [PicoShare issue tracker](https://github.com/mtlynch/picoshare/issues) is the better place.

## Ways to reach me

| | |
|---|---|
| Bug report | [Open an issue](https://github.com/apps4selfhosted/picaroa/issues/new?template=bug_report.yml) |
| Feature request | [Open an issue](https://github.com/apps4selfhosted/picaroa/issues/new?template=feature_request.yml) |
| Private request | [Support form](https://www.picaroa.app/en/support/) |

Replies usually within one to two days. Issues here are read and triaged by hand; development
itself happens in a private tracker, so an issue may be closed with a note naming the version
that fixes it rather than a commit link.

## Please do not post

Server URLs, API tokens, passwords or anything else that would let a stranger reach your
PicoShare instance. Please check screenshots and logs for such details before attaching them.
